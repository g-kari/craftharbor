# Security

Do not include worlds, player lists, playit credentials, Discord webhook URLs, DPAPI files, private keys, or full unredacted logs in public issues.

For ordinary bugs, use repository issues with redacted reproduction details.
For security reports, use GitHub private vulnerability reporting if available. If it is unavailable, open a minimal issue asking the maintainer for a private reporting channel without disclosing exploit details or secrets.

This preview has not completed runtime validation of the new interface, auto-memory settings, and Discord integration.
There are no automatic exception, antivirus exclusion, security-policy modification, or safeguard-bypass features.
